# Aura MVP

Aura MVPは、商用DAW全機能の代替ではなく、日常の短い制作を最後まで完了できる技術プレビューとする。

## 含める機能

- アプリ起動とネイティブ／Rustブリッジの準備完了
- オーディオトラックの作成、名称変更、削除、リージョン配置と移動
- トランスポート、再生位置、テンポ、基本MIDIイベント
- プロジェクトの保存・再読み込みと undo/redo
- PCM16/24・float WAVの読み込み、書き出し、有限値保護
- ソフトウェアオーディオドライバによる再生経路
- Timeline、Mixer、Diagnostics、Piano Rollの基本UI
- サンドボックス化されたCLAP処理境界と失敗時のクリーンな停止

## MVP外

実機または外部SDKが必要な項目は、MVP達成を妨げない別ゲートとして扱う。

- AU/VST3の第三者プラグイン互換性とネイティブGUIの実機証明
- ARA2、Windows ASIO、MIDI 2.0機器の実機証明
- OpenUtauの実レンダラー往復
- 長時間・大規模プロジェクトの商用安定性保証

## 完了条件

`scripts/run_mvp_gate.sh` が終了コード0で完了し、起動準備、ワークスペーステスト、CLIの能力応答、リリース対象ソース監査を確認できること。外部SDKや実機依存の結果をMVP合格に混ぜない。
