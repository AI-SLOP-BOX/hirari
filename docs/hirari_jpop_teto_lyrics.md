# 光ほどける夜に

## Direction

120 BPM / A minor / J-pop vocal-synth arrangement. The existing Teto chorus
is placed at bars 17–32, 49–64, and 81–96 so the accompaniment follows the
actual rendered vocal instead of being layered onto an unrelated demo.
