# Hirari 現行ギャップ一覧

このページは、現在の公開版に残る未接続・未検証項目だけを扱う正本です。
過去の監査結果は [`archive/UNIMPLEMENTED_GAPS_2026-08-11.md`](archive/UNIMPLEMENTED_GAPS_2026-08-11.md) に保存しています。

## 外部環境に依存する項目

- 実オーディオデバイスの全機種マトリクス検証
- Windows ASIOバックエンドの実機検証
- 第三者VST3/AU/CLAPの網羅的互換性
- ネイティブプラグインGUI埋め込み
- ARA2パートナープラグイン連携
- Dolby Atmos等の外部レンダラー連携

## 製品化前に必要な確認

- 長時間・大規模プロジェクトの安定性測定
- UIから全Core機能を操作する統合確認
- JavaScriptコマンドREPLは未提供。Advancedの旧Console表示にあった架空の実行ログ、固定Bridgeアドレス、未実行のプラグイン走査表示は撤去し、現在は実ランタイム診断を表示する。未計測のメモリ使用量は表示しない。
- 未保存セッションの起動時復旧UIと保存済みプロジェクトの自動保存を接続済み。通常の自動・手動・別名保存と復旧トランザクション内の「復旧して別名保存」は、スナップショット収集後のシリアライズ・ディスク公開を直列ワーカーへ移した。自動保存の差分判定では集約JSONの二重生成とMIDIノートJSON化を除き、ネイティブレイアウトJSONのCXX境界越しの複製も避けた。保存スナップショット構築もレイアウトJSONを初回世代確認と共有するが、Core状態走査と最終整合性確認、復旧チェックポイントの作成・Core復元・UI再水和はUIスレッドに残る。再起動後復元、クラッシュ・電源断時の整合性は実機未検証。
- 実機I/Oを含む録音・再生・書き出しの回帰テスト

機械可読な判定は `engine_capabilities_json()` の `status` と
`verification` を参照してください。`implemented` はエンジン契約の実装を示しますが、
実機・第三者プラグインでの検証済みを意味しません。
