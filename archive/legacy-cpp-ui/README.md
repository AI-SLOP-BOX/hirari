# Archived native C++ UI

This is the superseded C++ window/workspace implementation. It is retained for
reference only and is not built by the application. The production desktop UI
is in `hirari-ui/` (Rust and Slint).

The small C++ utilities still used by graphics code or native contract sources
were moved to `src/graphics/ui_components/support/`; they are intentionally not
archived here.
